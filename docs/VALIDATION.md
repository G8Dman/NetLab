## Automation 0.4.1 — графический выбор при отправке

Вкладка «Отправить»: источники и локальные получатели выбираются по имени/IP,
содержимое источника запрашивается через прежний inspect. Список предметов

колесо и клавиатуру, чтобы не активировать элементы под списком.
