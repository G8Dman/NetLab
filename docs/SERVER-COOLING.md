# Сервер: температура, кулеры и усиление (Automation 0.6)

Это оборудование сервера управления автоматикой, включая сервер в любой ячейке шкафа.
ПК, ноутбуки, роутеры и ядро Mobile остаются со своими прежними функциями.

## Установка

1. Изготовь обычный кулер. ПКМ по серверу (в шкафу — по его ячейке).
2. Выключи сервер кнопкой Power, открой «Модули».
3. Выбери `cooling0` и установи кулер из инвентаря. В одном слоте помещается один кулер.
4. По желанию установи ускоритель в `accel0`, плату объёма в `buffer0`.
5. Включи сервер. Для двух улучшений используй улучшенный кулер.

Модули также доступны во вкладке **NetLab модули**. Они создаются на обычном
верстаке по отдельным дорогим рецептам; сборщик сетевых модулей их не выпускает.
Сохранение IP, правил, пароля и шаблонов по-прежнему требует карты памяти CISCO.
При обновлении уже построенные серверы тоже начнут греться: установи охлаждение.
Демонстрационный стенд `/netlab demo automation` уже включает обычный кулер.

## Что меняется

| Комплектация | Результат |
|---|---|
| Без платы объёма | До 64 предметов в одном запросе |
| Плата объёма | До 256 предметов в одном запросе |
| Ускоритель | Подготовка запроса: 200 → 50 мс; окно OFFER: 20 → 5 секунд |
| Обычный кулер | Охлаждает базовый сервер при обычной нагрузке |
| Улучшенный кулер | Рассчитан на усиленный сервер; медный радиатор и более мощный вентилятор |

Ускоритель сокращает серверные задержки, скорость самого Ethernet/оптики
и ограничения контроллера трафика сохраняются. Пакет ITEM_DATA всё равно должен
пройти свой настоящий сетевой маршрут до вставки предметов. Медленная сеть
останется медленной с любым ускорителем.

Большая партия разбивается на отдельные билеты с легальными стопками.
Например, 256 угля — четыре билета по 64. Предметы с лимитом 16 или 1 также
не объединяются в недопустимые стопки. Для забора из нескольких слотов
выставь «Слот источника: -1», выбери предмет и введи 256 вручную. Выбор
конкретного слота ограничивает извлечение этим слотом. Если доступна только
часть запрошенного, журнал сохраняет уже созданные билеты и сообщает объём.
Правила «Логики» поддерживают увеличенную партию; после снятия платы лимит
снова 64. Жидкости сохраняют предел 16 000 mB на запрос.

## Нагрев и защита

Температура среды — 25 °C. Сервер греется во включённом состоянии,
а запросы и партии добавляют тепло. Ускоритель и буфер повышают
постоянный нагрев; ускоритель также сильнее нагревается при обработке.

* От 70 °C: серверные задержки увеличиваются вдвое.
* От 90 °C: защита приостанавливает операции и выдачу грузов.
* После охлаждения до 60 °C: операции снова разрешены, очередь продолжает доставку.

Нет взрыва, исчезновения грузов или обнуления настроек от температуры.
Уже извлечённые предметы и жидкости остаются в журнале. При ошибке/перегреве
не повторяй всю большую партию вслепую: сначала посмотри её созданные билеты.
Console и физическая панель доступны для диагностики и выключения.
Температура видна в физической панели, очках и в приложении управления.
Кнопка «Сервер» в приложении обновляет показания. В Console: `enable`, `show server`.

Температура сохраняется в самом устройстве: чтение холодной карты, перенос,
перезаход и включение/выключение не сбрасывают её. Пока чанк выгружен,
температура не меняется. Выключенный, но загруженный сервер остывает.

Расход FE/тик: сервер 12; ускоритель +8; буфер +4; обычный кулер +2;
улучшенный +6. Максимальная комплектация требует 30 FE/тик.

## Рецепты

Каждый рецепт даёт один предмет. Сетки перечислены строками слева направо;
рецепты открываются в книге Minecraft после получения соответствующей платы,
а также видны в JEI.

**Улучшенная плата CISCO:** `RGR / CBC / RGR`.
R — красная пыль (4), G — золотой слиток (2), C — слиток Цискиума (2),
B — базовая плата (1). Золото используется для контактов, Цискиум — для основы.

**Ускоритель:** `QAQ / CRC / QAQ`.
Q — кварц (4, тактовый генератор), A — улучшенная плата (2),
C — медный слиток (2), R — повторитель (1, управляющая электроника).

**Плата объёма:** `AGA / CRC / AGA`.
A — улучшенная плата (4), G — золотой слиток (2), C — медный слиток (2),
R — компаратор (1, контроль буфера).

**Обычный кулер:** `ICI / CAC / IRI`.
I — железный слиток (4, корпус/вентилятор), C — медный слиток (3, теплоотвод),
A — улучшенная плата (1), R — красная пыль (1).

**Улучшенный кулер:** `AGA / CFC / IGI`.
A — улучшенная плата (2), G — золотой слиток (2), C — медный блок (2,
увеличенный радиатор), F — обычный кулер (1), I — железная решётка (2).
