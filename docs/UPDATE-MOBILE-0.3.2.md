# NetLab Mobile 0.3.2-alpha

SIM-карты теперь восстанавливают приватные данные независимо от того, какой
игрок их держит. Передача карты другому игроку и перезаход больше не зависят
от последних 32 конфигураций в личном кэше выпустившего её игрока.

Телефоны и SIM используют постоянное хранилище мира. Для каждого предмета
хранится последняя версия; устаревший пакет инвентаря не может отменить
вставку SIM или вернуть извлечённую карту. Ключ SIM и история терминала
остаются серверными данными. При отсутствии исходных данных телефон
не заменяется молча новым пустым предметом.

Требуется NetLab 0.21.0-alpha или новее. Обновить Mobile нужно на сервере
и у подключающихся игроков. Остальные версии комплекта: основной мод
0.21.0-alpha, Automation 0.7.2-alpha, Sputnik 0.2.2-alpha.

Проверки: 9516 core; 21 новый сценарий передачи SIM, восстановления после
сохранения, старых пакетов и границ приватности. Также прошла цепочка
проверок меню, Mobile, жидкостей, охлаждения, Sputnik и переносных устройств.
Minecraft, клиент, сервер и существующие миры для тестов не запускались.
