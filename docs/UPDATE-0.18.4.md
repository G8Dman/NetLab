# NetLab 0.18.4 / Sputnik 0.1.4 — восстановление радиопортов

При размещении предмета Sputnik с пустым приватным компонентом конфигурации
наружный радиоблок мог получить общий профиль Switch-PT вместо BUC/LNB.
Инициализаторы теперь зарегистрированы для всех видов оборудования Sputnik;
в шкаф по-прежнему устанавливаются только HUB и интернет-шлюз.

При размещении или загрузке повреждённого блока без подключённых кабелей
восстанавливаются его штатные порты. Сохраняются идентичность, владелец,
настройки Sputnik и применимые LAN-адреса/маршруты. Корректные устройства,
включая их намеренно выключенные интерфейсы, остаются без изменений.

Команда interface теперь принимает точные имена без цифрового суффикса:
TX-IF, RX-IF, BUC-TX и LNB-RX. Console по-прежнему не является интерфейсом
передачи данных. Скрытые аппаратные порты не восстанавливаются этой командой.

Библия не изменялась. Выполнены 9466 проверок модели и 1410 проверок
реестров/NBT/карт/геометрии/пакетов. Восстановление также проверено на копии
данных повреждённого блока из сохранения. Клиент, сервер и мир не запускались.

Готовые JAR: NetLab 0.18.4-alpha и Sputnik 0.1.4-alpha; версии Automation
0.6.1-alpha и Mobile 0.1.3-alpha сохранены. Sputnik требует NetLab 0.18.4+.
