# Доступ через Console

Если провод подключён, но Terminal не открывается, проверь питание именно
того устройства, к которому ведёт кабель (верхняя/нижняя ячейка независимы).
У 3650-24PS сначала установи AC-POWER-SUPPLY в power0 или power1, затем
включи питание. SFP-трансивер не заменяет блок питания. В 0.9.4 Terminal
показывает эту причину явно вместо общего сообщения об отсутствии кабеля.

В 0.9.3 ноутбук использует отдельный модуль USB-RS232. Открой Desktop →
«Физическая панель / модули», выключи питание, выбери «Модули» → `usb0`,
установи USB-RS232 и включи питание. После установки на корпусе видны адаптер
и голубой разъём RS232. Перед извлечением выключи питание и отсоедини кабель.
USB-RS232 есть в творческой вкладке NetLab; рецепт — железный слиток + медный
слиток + redstone. У настольного ПК RS232 встроен. Старые ноутбуки получают
предустановленный адаптер, чтобы сохранить уже проложенные соединения.

Передняя панель при размещении обращается к игроку; старые блоки смотрят на
север. Поворот учитывают разъёмы, кабели и выбор порта.

1. Возьми консольный кабель NetLab.
2. Выбери RS232 на ПК/ноутбуке и Console на роутере/коммутаторе.
   Это крайний справа физический порт. Подсказка при выборе показывает имя.
   В шкафу верхняя и нижняя половины выбирают независимые устройства.
3. ПКМ по ПК/ноутбуку → Terminal (RS232, 9600 8N1).
4. Выполняй команды устройства; Command Prompt предназначен для самого ПК.

IP-адрес и DHCP для консоли не требуются. Прямой клик по роутеру или
коммутатору открывает физическую панель. Сервер отклоняет команды,
отправленные напрямую на сетевое устройство. При каждом запросе Terminal
проверяет загруженность обоих устройств и взаимное подключение кабеля.
После разрыва соединения снова открой ПК и приложение Terminal.

Указанные параметры 9600 8N1 фиксированы; побайтовая UART-линия не моделируется.
Проверены сборка и Java-тесты совместимости портов и изоляции от Ethernet.
