# NetLab 0.23.2: понятное сообщение вместо HTML

При отключении от сервера HTML-ответы с `Service unavailable` или `The request is blocked` теперь показываются так:

> Арабская ошибка, перезайти в лаунчер

Замена работает на клиенте, в том числе при входе через PortHол. Остальные причины отключения — таймаут, неверная сессия, бан, несовместимые моды — сохраняются. Кнопка возврата, ссылки на отчёт и озвучивание экрана используют стандартное окно Minecraft.

Это замена отображаемого сообщения. Она не обходит авторизацию и не восстанавливает доступ к заблокированным сервисам Mojang/Microsoft. Повторный вход в лаунчер может не помочь, если сервис всё ещё недоступен.

## Установка

Замени основной `netlab-0.23.1-alpha.jar` на `netlab-0.23.2-alpha.jar` в папке `mods` клиента при закрытой игре. Два основных NetLab одновременно оставлять нельзя. Аддоны сохраняют версии: Automation 0.7.4, Mobile 0.4.2, Sputnik 0.3.2, Media 0.1.2, Academy 0.1.1. Для отображения нового текста обновлять сервер не требуется: сетевой протокол не менялся.

Новых сторонних зависимостей нет. Клиентский mixin находится в списке `client` и не загружает классы интерфейса на выделенном сервере.

## Проверка

- `./dev.sh --offline build`: сборка шести JAR, **10 100** проверок модели.
- `python tools/check_academy.py`: **681 579** проверок Academy и **63** проверки сообщений отключения на настоящих текстовых компонентах Minecraft. Проверены HTML со скриншота, разные регистры и локали, составные компоненты, сохранение отчётов и неизменность обычных причин отключения.
- По байткоду Minecraft 1.21.1 проверены точная сигнатура конструктора и поле, используемые клиентским mixin.

Игра, графический экран, сервер и мир не запускались. Применение mixin и внешний вид окна в живом клиенте пользователь проверяет самостоятельно.
