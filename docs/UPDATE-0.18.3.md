# NetLab 0.18.3 — единое сохранение конфигурации

`write memory`, `wr`, `wr mem` и `copy run start` сохраняют текущую конфигурацию
всех консольных устройств, включая Automation, Mobile и Sputnik. Из режима
настройки доступны `do write memory` и `do copy running-config startup-config`.
Прежняя команда NetLab `memory write` остаётся псевдонимом. `memory read`
сохраняет прежнее назначение: применить настройки с установленной карты.

Запись обновляет startup-config и активирует установленную карту CISCO, не
читая старые настройки поверх работающего устройства. Перед записью сервер
автоматизации сохраняет своё текущее состояние приложения. Без карты устройство,
которому она нужна, сообщает об ошибке вместо ложного подтверждения сохранения.
Пустые карты по-прежнему автоматически записывают последующие изменения.
ПК и ноутбук используют встроенную память.

Tab у устройств дополнений теперь использует общий синтаксис, когда команда
не относится к собственным командам дополнения. На запросе пароля команды
сохранения и автодополнение не перехватывают ввод.

В библии и справке дополнений исправлено название команды. В Mobile добавлена
проверка `shutdown` оптических портов BBU/RRU и пример их включения. `show mobile`
показывает административное состояние портов и наличие кабеля; наличие кабеля
не является подтверждением работающего линка. Сохранённый `shutdown` обновление
автоматически не отменяет.

Состав: NetLab 0.18.3-alpha, Automation 0.6.1-alpha, Mobile 0.1.3-alpha,
Sputnik 0.1.3-alpha. Дополнения этого комплекта требуют NetLab 0.18.3-alpha+.
Сторонние зависимости не изменились.

Синтаксис сохранения сверён с [документацией Cisco](https://www.cisco.com/c/en/us/td/docs/switches/campus-lan-switches-access/Catalyst-1200-and-1300-Switches/cli/C1200-cli/file-system-commands.html).
Проверки выполняются без запуска клиента, сервера, мира и GameTest.

Проверено: 9452 проверки чистой модели, аудит 1008 форм команд, 499 проверок
реестров/конфигурации и 359 проверок Mobile/NBT/безопасности. Сохранённые настройки
LAN дополнительно проверены в чистой модели; это не проверка запущенного мира.
