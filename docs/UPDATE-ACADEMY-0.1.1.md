# NetLab Academy 0.1.1: одно дерево

В стандартном меню достижений Minecraft теперь **одна вкладка NetLab** вместо 15 вкладок разделов. Все 215 заданий входят в одно большое дерево: ветви связаны через предварительные задания, а название раздела видно в подсказке карточки. Подробный маршрут, условия и прогресс остаются в «Библии по CISCO» → «Обучение».

Minecraft рисует связь только с одним родителем; если задание требует несколько предыдущих шагов, сервер по-прежнему проверяет их все. Отсутствующие аддоны исключают свои ветви при загрузке данных. Остальные моды сохраняют собственные вкладки.

## Обновление

Замени `netlab-academy-0.1.0-alpha.jar` на `netlab-academy-0.1.1-alpha.jar` на клиенте и сервере. Два файла Academy одновременно оставлять нельзя. Остальные моды текущего комплекта: NetLab 0.23.1, Automation 0.7.4, Mobile 0.4.2, Sputnik 0.3.2, Media 0.1.2.

Все ID 215 заданий и критерии зачёта сохранены. Каталог и файл прогресса не менялись; при входе сервер восстанавливает заработанные отметки и открывает общий корень. Удалены только 15 служебных заголовков старых вкладок, которые не являлись заданиями.

Academy требует основной NetLab 0.23.0 или новее; сторонние библиотеки ему не нужны. [Зависимости всего комплекта](../README.md) и [правила зачёта](UPDATE-ACADEMY-0.1.0.md).

## Проверки

- `./dev.sh --offline build`: сборка шести JAR и 10 100 проверок модели.
- `python tools/check_academy.py`: **681 579 проверок**. Настоящие кодеки Minecraft прочитали 216 определений: 215 заданий и один общий корень.
- Для 256 сочетаний модов при двух вариантах политики AE2 построено настоящее `AdvancementTree` и выполнена стандартная разметка `TreeNodePosition`: один корень, все доступные узлы соединены, нет потерянных родителей или совпадающих ячеек.
- Проверены сохранение прогресса, удаление и возврат аддонов, зависимости финалов, страницы книги и подсветка поиска.

Клиент Minecraft, сервер и мир не запускались. Внешний вид и прокрутку большого дерева в игровом окне пользователь проверяет самостоятельно.
