# NetLab 0.19.0 — приложения Cisco Pocket

Телефон NetLab Mobile становится сетевым клиентом с тремя независимыми слотами.
Предметы устанавливаются из инвентаря во вкладке «Модули», извлекаются обратно,
сохраняются вместе с SIM и физической идентичностью телефона.

| Модуль | Дополнение-владелец | Назначение |
|---|---|---|
| Диагностика Cisco Pocket | Mobile 0.2.0 | Ping игровых IP, TCP/UDP, порт и данные пакета |
| Браузер Cisco Pocket | Sputnik 0.2.0 | Настоящие сайты через мобильный маршрут и интернет-шлюз |
| Автоматика Cisco Pocket | Automation 0.7.0 | Управление интерфейсами, предметами, жидкостями, правилами и рецептами |

Модуль автоматики перед установкой привязывается ПКМ по своему серверу с IP
и настроенным management password. Пароль по-прежнему вводится при входе и
не хранится на модуле. Привязка проверяет физический ID сервера и измерение;
замена блока другим с тем же IP не переносит права. Обычный вход с ПК остаётся
ограниченным локальной LAN/VLAN, телефон использует маршрут к привязанному серверу.

Телефон получает IP от EPC и передаёт данные через существующие LTE-очереди,
шифрование радио, BBU, проводной транспорт и маршрутизаторы. Очки показывают
переход между игроком и антенной. Для работы нужно держать телефон в руке и
иметь активную зарегистрированную SIM. Потеря телефона, SIM, радиосвязи или
нужного модуля прекращает доступ. Радиозащита не заменяет VPN проводного участка.

Браузерный модуль добавляется именно Sputnik. Дополнения не получают жёсткой
зависимости друг от друга; совместная работа идёт через API основного NetLab.
На клиенте Sputnik остаётся необходим Rinku 3.0.4. Для телефона поддержан
локальный звук браузера; внешние колонки ПК работают как раньше.

Раздел Sputnik в библии переписан по устройствам: питание/память, кабели,
наведение, таблица адресов, Console BUC/LNB, модема, HUB, интернет-шлюза,
Command Prompt ноутбука и подключение EPC через маршрутизатор. Поясняются
различия LAN/Satellite0/0, IP-шлюза/поля браузера, ID модема/тарелки и обратных
маршрутов к мобильному пулу. В Mobile и Automation добавлены статьи о телефоне.

Проверки: 9484 проверки модели, 1424 проверки реестров/NBT/пакетных кодеков,
а также настоящая HTTPS-страница через штатный SOCKS и модель пути
телефон → EPC → маршрутизатор → VSAT → HUB → интернет-шлюз. При обрыве
спутникового участка доставка прекращается. Это проверка транспорта и модели;
игровые окна и действия в запущенном мире не проверялись. Minecraft, сервер,
мир и GameTest не запускались. Нативный браузер Windows в этой сессии не проверялся.

Комплект: NetLab 0.19.0-alpha, Automation 0.7.0-alpha, Mobile 0.2.0-alpha,
Sputnik 0.2.0-alpha. Дополнения этого комплекта требуют NetLab 0.19.0-alpha+.
