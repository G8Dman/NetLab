# NetLab Academy 0.1.0 / NetLab 0.23.0

Учебный маршрут находится в **«Библии по CISCO» → «Обучение»**. Отдельного учебного окна нет. `/netlab academy` открывает ту же книгу сразу на маршруте.

В дополнении 215 заданий и 29 шагов основного курса. В книге видны цель, результат для зачёта, предыдущие шаги, состояние, подсказка и раздел справочника. Выполненные действия сохраняются до завершения предыдущих заданий; обычное меню достижений Minecraft также показывает дерево.

## Поиск

Строка ищет по заголовкам и полному тексту **всех установленных разделов книги**. Все вхождения выделяются тёмно-красным, жирным и подчёркиванием. Поиск не зависит от регистра, поддерживает русский текст и буквальные символы. Подсветка сохраняется при переносе строк и смене страницы. Пустой запрос возвращает статьи выбранного раздела.

Обновление прогресса с сервера сохраняет введённый запрос, страницу и фокус поля. Сеть не пересылает весь каталог при каждом изменении: клиент получает только доступные ветки и отметки.

## Установка

Нужны Minecraft 1.21.1, NeoForge 21.1.265, Java 21 и основной NetLab **0.23.0-alpha**. Academy устанавливается на клиент и сервер. Сторонние библиотеки для Academy не нужны.

Текущий согласованный комплект:

- NetLab 0.23.0-alpha;
- Automation 0.7.4-alpha;
- Mobile 0.4.1-alpha;
- Sputnik 0.3.1-alpha;
- Media 0.1.1-alpha;
- Academy 0.1.0-alpha.

Если другие аддоны уже установлены, обнови их до версий этого комплекта: они содержат события учебного прогресса. Старые версии аддонов вместе с Academy не допускаются проверкой зависимостей.

Automation, Mobile и Sputnik необязательны для Academy. Media дополнительно требует Sputnik и Simple Voice Chat; браузерные функции Sputnik требуют Rinku на клиенте. Эти зависимости перечислены отдельно в README и MODS.json, сторонние JAR в готовый комплект NetLab не входят.

## Доступность и сохранение

Отсутствующий аддон исключает свою ветку на загрузке данных сервера. Его задания не появляются в книге или дереве. Пересечения появляются только при наличии всех нужных дополнений. Carry On, MineColonies и AE2 тоже необязательны; задача AE2 доступна только при уже включённой сервером политике ограничения автоматики.

Прогресс хранится по UUID игрока в `data/netlab_academy.dat` основного измерения мира. Удаление аддона скрывает его задачи, сохраняя отметки; после возврата аддона отметки восстанавливаются. Добавление новых веток меняет текущую цель «Знаю свою сборку», не отбирая ранее полученный значок. Награды не создают предметы, FE, опыт, права или доступ к чужим устройствам.

По умолчанию общий финал не требует внешнего сайта, микрофона или сторонних баков. Отдельные задания этих сервисов доступны, но общий итог использует доступные промежуточные цели. Параметры в `<мир>/serverconfig/netlabacademy-server.toml`:

```toml
requireExternalInternetForFinal = false
requireMicrophoneForFinal = false
requireFluidTanksForFinal = false
```

[Пример настройки](../config-examples/netlabacademy-server.toml). Для основного курса нужен любой разрешённый сборкой источник NeoForge FE; творческий генератор не требуется.

## Что проверяется

События изготовлений, физических подключений и установки оборудования привязаны к действию игрока. CLI проверяется по изменению состояния и результатам сетевой модели. Доставка предметов/жидкостей подтверждается после фактической вставки, голос — после доставленных кадров в обе стороны. Просмотр и аудиовывод дополняются клиентскими подтверждениями при действующем серверном сеансе. Приватные настройки, пароли, содержимое микрофона и веб-страниц в учебном прогрессе не хранятся.

Изготовления не выдаются за простое получение чужого предмета или присутствие возле готового стенда. Такой стенд можно использовать для заданий на успешную работу сети.

## Проверки выпуска

- `./dev.sh --offline build`: **10 100** проверок модели, сборка шести JAR.
- `python tools/check_academy.py` (первое заполнение кэша: `--online`): **377 957** проверок каталога и прогресса, 256 наборов модов при двух вариантах политики AE2, отсутствие потерянных родителей, сохранение результатов и динамических финалов. Проверены настоящие кодеки 230 записей достижений: 215 заданий и 15 заголовков.
- Проверена загрузка учебных страниц на classpath только основного NetLab и Academy, без классов Automation, Mobile, Sputnik, Media, Chromium или Voice Chat.
- Проверены реальные текстовые компоненты и сохранение подсветки при переносе русских слов.
- `python tools/check_media.py`: существующие проверки реестров, карт, модулей, моделей, голосового API и рецептов. **1 218** проверок рецептов: 88 рецептов и 132 предмета пяти содержательных модов; Academy не добавляет предметов или рецептов.

Minecraft, сервер, мир, GameTest, микрофон и графический клиент для этих проверок не запускались. Полный ручной прогон 215 сценариев в мире и визуальная проверка книги остаются игровыми проверками.

## Быстрая проверка в игре

1. Открой книгу → «Обучение» → «Маршрут и прогресс»: появляется B01 и следующий шаг.
2. Изготовь базовую плату до завершения предыдущих шагов: действие сохраняется, но зависимости не обходятся.
3. Найди `VLAN`, затем `консоль`: результаты приходят из разных разделов, все совпадения в статье выделены. Проверь переходы страниц и набор запроса при обновлении прогресса.
4. Сними очки/отключи кабель во время неуспешного теста: один ввод `ping` не должен давать успешную связь.
5. Проведи передачу в Automation и звонок Media: статус ожидания/ACTIVE не заменяет доставку и голосовой обмен.
6. На копии мира убери необязательный аддон и верни его с соблюдением его зависимостей: ветка исчезает и возвращается с прежними отметками.

Полный список задач: [NETLAB-ACHIEVEMENTS.md](NETLAB-ACHIEVEMENTS.md).
