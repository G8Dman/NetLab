# NetLab Automation 0.7.3 — автоматизация через CISCO

Добавлено необязательное серверное правило для сборок с AE2: ручное ME-хранилище остаётся, автоматизация выполняется через NetLab. Сам AE2 для работы NetLab не требуется и в загрузки NetLab не включён.

Для включения в `config/netlabautomation-server.toml`:

```toml
disableAe2Automation = true
```

Готовый файл находится в `config-examples/`. Настройка по умолчанию выключена; владелец сборки выбирает её сам. Для отдельного мира NeoForge позволяет переопределить её в `saves/<мир>/serverconfig/netlabautomation-server.toml`. Перезапустите игру или сервер после изменения. На выделенном сервере устанавливаются обновлённый Automation и конфигурация сервера; клиенты также обновляют Automation.

При попытке поставить устройство автоматизации, открыть его настройки либо заказать автокрафт игрок получает сообщение **«Нет, используй CISCO :)»**. Кабельный терминал продолжает открываться, даже если на том же блоке кабеля установлена запрещённая шина.

Останавливаются импорт/экспорт предметов и жидкостей, автоматическое пополнение интерфейсов, поставщики шаблонов, сборщики, ME IO Port, плоскости формирования/уничтожения и выполнение уже существующих заданий CPU. Новые задания отклоняются до резервирования ингредиентов. Автоматические операции с ME-хранилищем и внешними предметными capability AE2 также отклоняются: обход через воронку или трубы в ME-сундук не включает логистику обратно.

Остаются ручные ME-терминалы, ME-сундук с интерфейсом доступа к ячейке, диски, ячейки, кабели, контроллеры, ручное внесение/извлечение и ручной крафт в терминале. Шины хранения можно использовать для доступа к внешнему хранилищу вручную. Содержимое существующих устройств не удаляется, демонтировать устройства и забрать их инвентарь можно. Ранее начатый автокрафт приостанавливается с его буфером: отключите правило для штатного завершения или возврата зарезервированных ресурсов. При включённом правиле машинное внесение предметов во входной буфер ME-сундука также не переносит их в ячейку; используйте ручной терминал.

Проверена установленная версия **AE2 19.2.18 / Minecraft 1.21.1 / NeoForge 21.1.265**. Проверка запускает настоящий Sponge Mixin transformer на 13 классах AE2 и вызывает изменённые методы: ручные операции проходят, машинные возвращают нулевой перенос, входящий стек сохраняется целиком, существующие устройства останавливаются. Отдельно проверяется отсутствие AE2. Клиент, сервер Minecraft, миры и GameTest не запускаются.

```bash
./dev.sh --offline build
python tools/check_ae2_compat.py /path/to/appliedenergistics2-19.2.18.jar
```

Функции шин сверены с [официальным руководством AE2](https://guide.appliedenergistics.org/1.21/items-blocks-machines/export_bus/); конкретные точки интеграции проверены по байткоду установленного JAR. Отдельные дополнения к AE2, предоставляющие собственные нестандартные хранилища или механизмы переноса, требуют самостоятельной проверки.
