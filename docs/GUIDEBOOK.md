# Библия по CISCO

Основной мод NetLab 0.9.1-alpha добавляет предмет `netlab:cisco_bible`.
Книга находится в начале творческой вкладки NetLab; рецепт — книга + redstone
в произвольных ячейках. Для выдачи командой: `/give @s netlab:cisco_bible`.
Открывается ПКМ с книгой в руке.

Два основных раздела: «Блоки» и «Команды». Содержимое включает установку
оборудования, шкаф на два устройства, кабели, модули, Wi-Fi, диагностические
очки, доступ к консоли и примеры настройки сети. Каталог модулей формируется
из Hardware.CATALOG, справочники команд по режимам — из CommandGrammar.
Поиск проверяет заголовок и текст в выбранном разделе. Колесо над оглавлением
прокручивает статьи; над текстом перелистывает страницы. Page Up / Page Down
работают, когда фокус не в строке поиска. Esc или крестик закрывают книгу.

Automation 0.1.1-alpha добавляет «Автоматика»: интерфейсы, сервер, правила,
управление, журнал, перехват и VPN. Основной мод не зависит от классов
дополнения. Секция загружается только при наличии его клиентских ресурсов.

Для других дополнений/ресурспаков: `assets/<namespace>/netlab_guide/*.json`.
Формат — объект с `id` (namespace:section), `title`, `order` и массивом
`articles`; статья имеет уникальные в разделе `id`, `title`, `body`.
Переносы строк в body задают абзацы/строки команд; длинные строки автоматически
переносятся по ширине страницы. order задаёт порядок вкладок: 10 «Блоки»,
20 «Команды», 30 «Автоматика». Обычный ресурспак может переопределять файлы.
После перезагрузки ресурсов заново открой книгу.

Проверка: сборка обоих JAR, существующие 325 core-проверок и проверка JSON,
рецепта, локализаций и условного наличия секции по содержимому архивов.
Minecraft/Prism/GameTest не запускаются; графическая проверка остаётся за
пользователем.
